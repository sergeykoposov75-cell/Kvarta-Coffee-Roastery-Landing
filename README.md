# Kvarta-Coffee-Roastery-Landing
A landing page for a small coffee roastery. Freshness is the main thing they sell: the beans arrive at the customer’s location 1–3 days after roasting. Cutomers aged 25–45, who drink coffee at home or in the office; most of them access the site via their phone. The main goal is to get an order. The manager calls back and completes the order.
